# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep disagreement about the work
and not the person, and accept that a maintainer's decision on a change is
final for that change.

## Reporting

Report conduct concerns to the maintainers through GitHub's private
vulnerability reporting on this repository (**Security → Report a
vulnerability**). It is the one private channel the repository offers, it
reaches only the maintainers, and a conduct report filed there is treated with
the same confidentiality as a security one. Reports are reviewed promptly and
handled as confidentially as the situation allows.

## Enforcement

Maintainers may remove, edit or reject comments, commits, issues and pull
requests that do not align with this code, and may temporarily or permanently
restrict participation for behaviour they deem inappropriate, threatening,
offensive or harmful.
